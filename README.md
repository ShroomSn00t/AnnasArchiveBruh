# Anna's Archive EBook Plugin for Compass / Harbor

Custom eBook source extension providing search, metadata, and download mirrors from [Anna's Archive](https://annas-archive.gl).

## 🚀 How to Install in Compass / Harbor

1. Open **Compass** or **Harbor**.
2. Navigate to **Extensions** / **Sources** -> **Add Repository**.
3. Paste the following URL:
   ```text
   https://raw.githubusercontent.com/ShroomSn00t/AnnasArchiveBruh/main/repo.json
   ```
4. Click **Install** next to **Anna's Archive**.

## ✨ Features

- **Search**: Search across millions of titles, authors, and books.
- **Popular / Trending**: Browse popular and recently uploaded titles.
- **Rich Book Details**: Cover artwork, synopsis, author, publisher, ISBN, and file specs.
- **Mirror Aggregation**: Direct links to IPFS gateways (Cloudflare, IPFS.io, Pinata), Library Genesis (Libgen), and Anna's Archive slow partner servers.
- **Mirror Resilience**: Automatic failover across active Anna's Archive domains (`.gl`, `.pk`, `.gd`, `.se`, `.li`, `.org`).
- **Tag Filtering**: Filter by format (EPUB, PDF, MOBI, CBR/CBZ), content type, and language.
